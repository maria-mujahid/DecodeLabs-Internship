# Decodelabs-internship

## Project Overview

This project was completed as part of my Data Analyst internship at Decodelabs. It focuses on cleaning a sales dataset containing approximately 1,200 records.

## Dataset

The dataset contains information about customer orders, products, quantities, prices, payment methods, order statuses, discounts, coupon codes, and sales sources.

## Project Objectives

* Inspect the dataset and identify data quality issues.
* Handle missing values.
* Clean and prepare the dataset for further analysis.
* Save the cleaned dataset in Excel format.

## Tools Used

* Microsoft Excel
* Python 

## Project File

'decodelabs_cleaned_dataset_project_1.xlsx'

## Outcome

The project produced a cleaned sales dataset ready for further analysis.
