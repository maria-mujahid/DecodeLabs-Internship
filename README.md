### Project 1: Sales Data Cleaning

**Tools:** Microsoft Excel, Python

**Description:**

This project focuses on cleaning and preparing a sales dataset containing approximately 1,200 order records.

**Key Tasks:**

* Inspected the dataset to identify data quality issues.
* Handled missing values.
* Cleaned and prepared the dataset for further analysis.
* Saved the cleaned dataset in Excel format.

**Project File:** `decodelabs_cleaned_dataset_project_1.xlsx`

**Outcome:** Produced a cleaned dataset ready for further analysis.

### Project 2: Exploratory Data Analysis (EDA)

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook

**Description:**

This project explores a sales orders dataset to understand its characteristics, identify patterns, and examine potential outliers.

**Key Tasks:**

* Examined descriptive statistics.
* Analyzed daily and monthly order patterns using visualizations.
* Applied the Interquartile Range (IQR) method to detect potential outliers.
* Interpreted the results to gain insights into the data.

**Project File:** `decodelabs_exploratory_dataanalysis_project2.ipynb`

**Outcome:** Explored the dataset using statistical analysis, visualizations, and outlier detection.
